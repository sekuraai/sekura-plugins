# Sekura for Cline

Sekura scans a GitHub repository for vulnerabilities and delivers a report with proof for every finding; from your agent you can see your repositories, start a scan you have approved, read the findings, and manage a schedule.

## Connect

Cline, Settings, MCP Servers, Remote Servers: name `sekura`, URL `https://sekura.ai/mcp`. Cline opens the Sekura sign-in page; sign in with GitHub and approve.

## What it does

Read tools (free): account, repositories granted to the Sekura GitHub App, scans, findings, report links, plans, a billing summary without card numbers.

Write tools, each quoted first and run only after you agree in the conversation: start a Sekura Once scan, put a repository on Sekura Always, bring a scheduled run forward, cancel a scan or a plan. A card is charged only after you approve the quoted amount; otherwise you get a Stripe Checkout link.
